# My Grandpa's Collection — The Julio Paez Collection

A public memorial archive of historical Popular Mechanics DIY ideas, with clearly separated modern engineering suggestions.

## Publish on GitHub Pages

1. Open **Settings → Pages** for this repository.
2. Under **Build and deployment**, choose **GitHub Actions**.
3. Open **Actions → Publish Grandpa's Collection** and run the workflow if it has not run after enabling Pages.
4. Wait for a successful deployment, then use the Pages URL provided by GitHub.

Site source: `index.html`. The initial archive entries are research leads and not validated build plans. Original page scans and technical details require verification.

## Daily curation

The ChatGPT scheduled task prepares one new historical project and five independent modern engineering suggestions. **It does not automatically update this repository.** To publish daily updates, an authenticated bridge must write approved entries into a source file or GitHub repository, triggering this workflow. Never automate publishing unverified drawings, dimensions, or instructions.

## Copyright and safety

Use source links rather than reproducing copyrighted scans without rights. Independently validate any woodworking or machinery build for structural loads, blade clearance, guarding, dust extraction, electrical compliance and material suitability before construction.
